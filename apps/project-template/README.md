# Project Template

Jack Tan Studio 子应用标准脚手架。

## 复制后必改清单

- [ ] 目录名：`apps/project-template` → `apps/jack-xxx`
- [ ] `package.json` 中的 `name`、`description`
- [ ] `vite.config.ts` 中的 `base`（例如 `/projects/jack-lens/`）
- [ ] `index.html` 中的 `title`、`meta`、`data-project`
- [ ] `src/main.tsx` 中的 `projectId`
- [ ] `src/App.tsx` 中的页面内容
- [ ] `apps/studio/src/data/projects.ts` 中注册新项目
- [ ] `scripts/merge-dist.mjs` 中添加产物拷贝（如果保持单 Pages 部署模式）
